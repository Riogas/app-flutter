# Home V2 (Rediseño pantalla principal) — Plan de implementación

> **Ejecución:** inline en sesión (tareas fuertemente acopladas sobre archivos nuevos compartidos + iteración visual en dispositivo). Commits por tarea sobre `refactor/gps-persistente`.

**Goal:** Rediseñar la pantalla principal de MoveIT como app de logística profesional (cabecera ilustrada, resumen operativo, tarjeta de pedido actual con mini-mapa, siguientes pedidos, estado técnico, tab Promociones) manteniendo el diseño viejo accesible vía toggle en Configuración.

**Architecture:** `HomePage` conserva TODO su lifecycle/lógica (streams, FCM, estado del móvil, contadores). Según flag `UiPrefs.homeV2` renderiza el scaffold legacy actual o `HomeV2Scaffold` (presentación pura que recibe callbacks/notifiers de HomePage y lee `PersistentStreamManager`). Nada del diseño viejo se borra.

**Tech stack:** Flutter, flutter_map + FMTC (tiles osmtileserver.riogas.uy), Firestore vía PersistentStreamManager, Hive, battery_plus, connectivity_plus, geolocator, cached_network_image.

## Global Constraints

- NO tocar backend GeneXus. Firestore sí (colección nueva `Promociones-{escenario}` leída por la app; se carga a mano/GeneXus después).
- Diseño viejo intacto y conmutables en runtime: toggle pro en Settings, persistido en `usuarioBox` clave `uiHomeV2` (sobrevive logout), default **true**.
- Toda UI reactiva cuelga de `PersistentStreamManager` (no crear listeners Firestore paralelos, salvo query one-shot de entregas hoy — patrón `settings_page.dart:127-160`).
- Datos reales: pedido = campos EXACTOS (`ClienteDireccion`, `ServicioNombre`/`Defecto`, `Precio`, `PedidoObs`, `ubicacion` GeoPoint, `FchHoraMaxEntComp`, `Tipo`, `id`). Cliente/producto detallado NO existe fuera de `DetalleHTML` → la tarjeta muestra dirección como principal.
- "Prioridad" = minutos restantes a `FchHoraMaxEntComp` (mapeo existente `getDelayInfo`, constantes 40-43): alta (rojo/naranja) / media / normal.
- "Zona asignada" no existe como dato → indicador reemplazado por Pendientes.
- Distancia = `Geolocator.distanceBetween` (línea recta) + ETA estimada a 30 km/h urbanos. Sin routing.
- "Iniciar viaje" = abrir navegación externa: `WazeURL` del pedido si existe, sino `geo:` URI con `ubicacion`.
- "Ver detalle" reutiliza flujo real (lectura + `OrderDetailPage`). "Devolver pedido" = `OrderDetailPage` con `autoFinalize: true` (abre el diálogo de finalización con TODAS las validaciones existentes de GPS/distancia).
- Cabecera: fondo remoto `background_home.png` → fallback `background_delivery_{dia|noche}.png` → color sólido. Degradado azul oscuro encima. Logo RGDelivery recortado (ClipRect como login).
- Paleta: fondo #F2F6FA, azul oscuro #0D2B4E, acción #1E88E5, celeste #E3F2FD, verde #43A047, naranja #F57C00, rojo #E53935. Radius 16-24, botones ≥52px, sombras suaves. Español rioplatense.
- Gate por tarea: `flutter analyze` sin errores nuevos + `flutter build apk --debug` OK. Milestones visuales: instalar en BV9200 + screenshot.

## Tareas

### T1 — Toggle de diseño + esqueleto V2
- Create: `lib/services/ui_prefs.dart` — `UiPrefs`: `ValueNotifier<bool> homeV2` + `init()` (lee `usuarioBox.uiHomeV2`, default true) + `setHomeV2(bool)` (persiste + notifica).
- Modify: `settings_page.dart` — card "Diseño de la aplicación" con Switch pro (icono, título, subtítulo "Nuevo diseño / Diseño clásico") insertada arriba de `_buildChangePasswordButton()`.
- Modify: `home_page.dart` `build()` — `ValueListenableBuilder(UiPrefs.homeV2)`: true → `HomeV2Scaffold`, false → scaffold actual (extraído a `_buildLegacyScaffold`).
- Create: `lib/pages/v2/home_v2_scaffold.dart` — Scaffold con IndexedStack `[PedidosTabV2, MapPage(), PromocionesPage]` + BottomNavigationBar 3 tabs (Pedidos/Mapa/Promos) con badges (pendientes, promos nuevas). Recibe de HomePage: `messageCountNotifier`, `onEstadoTap`, `estadoCooldownCheck`.

### T2 — Cabecera V2 (dentro de PedidosTabV2)
- Fondo con fallback chain + degradado `#0D2B4E`→transparente→`#0D2B4E`.
- Logo recortado izquierda; derecha: icono mensajes con badge rojo (→ `MessagePage` push) + avatar `CircleAvatar` con menú (Perfil→Settings, Configuración→Settings, Estado del móvil→onEstadoTap, Ayuda→tel constante 170 + manual, Cerrar sesión→`LogoutService.executeLogout(false, ...)` con confirmación).

### T3 — Resumen operativo (tarjeta flotante superpuesta a la cabecera)
4 indicadores con icono azul en círculo celeste: Pendientes (pedidosNotifier.length), Entregadas hoy (query one-shot `EstadoNro==2 && FchPara==hoy`, refresh al cambiar pedidosNotifier), Distancia recorrida (fuente de Settings), Última actualización (hora del último evento de pedidosNotifier).

### T4 — Tarjeta PEDIDO ACTUAL
- Header azul "PEDIDO ACTUAL" + chip prioridad (delay real).
- Dirección grande, Servicio/Defecto, Importe, Obs, min restantes; distancia + ETA calculadas.
- Mini-mapa flutter_map (tiles FMTC riogas, interactividad off): marker camión (posición actual), pin rojo destino, polyline azul recta.
- Botón principal "Iniciar viaje" (≥52px, icono navigation) → Waze/geo. Secundarios: "Ver detalle" (borde azul, flujo lectura real) y "Devolver pedido" (borde rojo, OrderDetailPage autoFinalize).
- Modify: `order_detail_page.dart` — param opcional `autoFinalize` que dispara `_validateBeforeShowingDialog` post-frame.
- Estado sin pedidos: tarjeta "Estás al día" + subtexto + mini-indicadores (estado móvil, GPS, última sync).

### T5 — SIGUIENTE PEDIDO + lista completa
Tarjeta compacta del 2º pedido (dirección, distancia desde pedido actual, ETA, chip prioridad). Fila "+N pedidos más en tu ruta" → bottom sheet con lista v2 (tap → mismo flujo detalle).

### T6 — Estado técnico
Tarjeta horizontal 4 indicadores: GPS (provider+servicio), Conexión (connectivity_plus), Sincronización (última emisión streams), Batería (battery_plus). Verde/naranja/rojo.
